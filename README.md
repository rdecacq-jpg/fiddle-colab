# Fiddle collaboratif

Éditeur HTML / CSS / JavaScript à plusieurs, en direct, sans compte.

## Lancer chez toi
    npm install
    npm start
Ouvre http://localhost:3000 : une salle est créée, copie le lien pour inviter.

## Mettre en ligne (gratuit) avec Render
1. Mets ce dossier dans un dépôt GitHub.
2. Sur render.com : New > Web Service > ton dépôt.
3. Build Command : `npm install`   Start Command : `npm start`
4. Tu obtiens une adresse https://xxx.onrender.com : c'est ton site.
Note : l'offre gratuite s'endort après inactivité (premier chargement lent),
et le code d'une salle est gardé en mémoire (perdu si le serveur redémarre).
